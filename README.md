# Baboot! (バブート!)

学校の授業やレクリエーションで使える、リアルタイム・マルチプレイヤー・クイズゲームです。

## プロジェクト概要
「Baboot!」は、先生（ホスト）が作成・提示したクイズに、生徒が自分の端末（スマホ、タブレット、PC）からリアルタイムで回答し、正解数や回答速度を競うオンラインゲームです。

Googleのクラウドデータベース「Firebase」を利用することで、複雑なサーバー構築なしに、リアルタイムな双方向通信を実現しています。

## 主な機能
- **直感的な操作**: 先生はクイズを提示し、生徒は4つの選択肢から選ぶだけのシンプルな仕組み。
- **6桁PINコード**: 複雑なURL不要。数字6桁を入力するだけで、簡単に同じルームに参加できます。
- **リアルタイムランキング**: 各問題終了ごとの中間順位発表と、最後に表彰台形式で発表される最終結果。
- **成績管理**: 回答結果をCSV形式でダウンロードし、集計や評価に活用可能。
- **マルチ言語対応**: 日本語、英語、中国語に対応しており、国際的な環境でも利用可能。

## ファイル構成
- `teacher.html`: 先生用管理画面
  - クイズの作成、読み込み、ルームのホスト（開催）
  - プロジェクター等での公開用画面
- `index.html`: 生徒用参加画面
  - PINコードとニックネームを入力して参加
  - 回答操作（4択ボタン）
- `agents.md`: AIエージェント向け技術仕様書（開発者向け）

## 使い方
1. **ホスト（先生）**: `teacher.html` を開き、クイズデータ（URLまたはテキスト）を読み込んで「ホスト」ボタンを押します。
2. **参加者（生徒）**: `index.html` を開き、画面に表示された6桁のPINコードと自分の名前を入力します。
3. **進行**: 全員が集まったら、先生が「スタート」を押してクイズが始まります。

## 技術仕様
- **フロントエンド**: HTML5, Vanilla JavaScript, Vanilla CSS
- **バックエンド**: Firebase Realtime Database
- **通信方式**: RTDBの状態同期によるイベント駆動型通信
